4. COMO EXECUTAR NO INTELLIJ IDEA
------------------------------------------------------------------------
1. Abra o IntelliJ IDEA.
2. Acesse 'File' -> 'Open...' e selecione a pasta raiz do projeto.
3. Configure o SDK para o Java 21:
   - Vá em 'File' -> 'Project Structure...' -> 'Project'.
   - Em 'SDK', selecione o Java 21.
4. Confirme que a pasta 'src' está definida como raiz de código fonte:
   - Clique com o botão direito na pasta 'src' -> 'Mark Directory as' -> 'Sources Root'.
5. Abra o arquivo 'src/main/Main.java'.
6. Execute clicando no ícone verde de 'Play' ao lado do método 'main' (ou pressione Shift + F10).

5. COMO EXECUTAR VIA TERMINAL (LINHA DE COMANDO)
------------------------------------------------------------------------
1. Abra o terminal e navegue até a pasta raiz do projeto.
2. Compile as classes criando a pasta de binários ('bin'):

   javac -d bin src/model/*.java src/hashtable/*.java src/main/*.java

3. Execute a classe principal indicando o diretório dos binários:

   java -cp bin main.Main

6. COMPORTAMENTO DO DESAFIO LÚDICO (MAIN.JAVA)
------------------------------------------------------------------------
A execução simula o gerenciamento de pergaminhos na Biblioteca da Brasilândia:
1. Exibição da tabela inicial vazia (M = 7) e Fator de Carga = 0,00.
2. Inserção de chaves com colisão intencional nos slots 0 (IDs 7, 14, 21) e 3 (IDs 10, 17).
3. Validação e bloqueio de chave duplicada (ID 14).
4. Busca por chaves com exibição da contagem exata de comparações.
5. Remoção do ID 14 (nó intermediário da lista encadeada) e recálculo do Fator de Carga.
6. Validação de acesso pós-remoção, confirmando a preservação da lista e a redução no número de comparações.
